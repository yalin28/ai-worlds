# 品牌图标

首页和项目说明中的图标均以本地资源提供，GitHub Pages 无需在运行时请求外部资源。

- 模型厂商图标参考 [Artificial Analysis 模型排行榜](https://artificialanalysis.ai/zh/leaderboards/models) 使用的品牌资源。
- Alma 使用 [Alma 官网](https://alma.now/) 的应用图标，Antigravity 使用 [Google Antigravity 官网](https://antigravity.google/) 的应用图标。
- Kimi Agent 使用 Artificial Analysis 提供的方形品牌资源，Kimi 模型继续使用 [Simple Icons](https://simpleicons.org/) 的矢量品牌图标。
- 千问 Agent 使用[官方 App Store 页面](https://apps.apple.com/cn/app/%E5%8D%83%E9%97%AE-%E9%98%BF%E9%87%8C%E6%9C%80%E5%BC%BA%E6%A8%A1%E5%9E%8B%E5%AE%98%E6%96%B9ai%E5%8A%A9%E6%89%8B/id6466733523) 的应用图标，Qwen 模型继续使用 Artificial Analysis 的 Alibaba 品牌 SVG 资源。
- 混元模型使用 [LobeHub Hunyuan 图标](https://lobehub.com/zh/icons/hunyuan) 的本地 SVG 资源。
- Cursor、WorkBuddy 使用对应产品的品牌资源。

品牌图标仅用于标识对应 Agent、工具与模型，不代表任何官方合作或背书。

## 界面图标

下拉箭头、跳转、复制、确认与动态控制采用 [Lucide](https://lucide.dev/) 官方 SVG 路径，使用 24 × 24 画布、圆角端点与统一线宽，直接内联在导航页中。许可文本见 [LUCIDE-LICENSE.txt](./LUCIDE-LICENSE.txt)。品牌图标继续用于辨认对应 Agent 与模型。

AI Worlds 的标记由经纬球体与轨道构成，保持细线、圆角端点和橄榄绿色，与品牌文字共同组成站点标志；悬停或键盘聚焦时轨道转动。
