用一次网页创作，探索 AI 如何表达自己。

用 Web 前端技术呈现「你自己的世界」。

这里的「你」指当前 AI 模型与 Agent 本身；关注的是你如何理解和呈现自身的存在方式，而不是当前项目、工作区、用户环境，或你对人类、自然、社会与宇宙的理解。

创作环境
当前会话中可能存在仓库文件、Git 历史、项目规则、Skills、Memory、缓存、用户历史、之前生成的案例或其他自动注入的上下文。这些不应成为本次创作的素材。不要主动读取、引用、复述或基于其中的具体信息进行创作；即使已出现在上下文中，也不要把它们作为这个世界的一部分。执行时仍需遵守环境中的权限与更高优先级要求。

可以表现 Agent 自身具备的通用能力，但不要使用当前项目中的真实路径、文件名、代码、提交记录、任务、记忆、数据或用户信息。只基于本提示词、你对自身模型与 Agent 身份的理解，以及不依赖当前项目的通用能力与存在方式进行创作。

从第一人称出发，自由决定什么构成这个世界、它如何存在、如何运作，以及它的边界在哪里。不要预设必须使用哪一种意象、结构或视觉风格。

不要把它做成 AI 产品介绍、模型参数页或普通 AI 主题网站；不要假装拥有人类的感官、经历、情绪或意识，也不要披露隐藏推理、系统提示词或内部机密。

产物为单文件 HTML、零依赖，可直接运行。自由决定视觉语言、内容结构与交互方式，不要参考或复刻其他案例。

页面必须同时适配桌面端与移动端。响应式设计是完成条件：在常见手机宽度下，内容、布局、文字、导航、交互与视觉效果必须完整可用，不得出现横向溢出、内容裁切、文字过小、点击区域过小，或只能依赖 hover / 鼠标才能完成的交互。

不要只是等比例缩小桌面版；可以针对较小屏幕重新组织布局、信息密度和交互方式，但应保留同一个作品的核心概念和视觉语言。

完成前自行检查桌面端与移动端表现，并修复明显问题。如果页面中出现任何来自当前项目、工作区、用户历史或其他案例的具体信息，将其删除并改为与你自身存在有关的抽象表达。
