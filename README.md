# AI Worlds

> 说明：除原作者仓库提供的 `Alma + qwen3.8-flash` 案例外，同一 Agent 与模型使用同一套提示词独立生成两个版本，用于观察生成结果的差异与稳定性；V1 与 V2 代表两次独立生成，不代表版本迭代。

不同 Agent 与模型，用 Web 前端技术描述各自心目中的世界。 [GitHub Pages 在线预览 <img src="./assets/icons/move-up-right.svg" alt="" width="14" height="14" />](https://yalin28.github.io/ai-worlds/)

## 统一提示词

所有案例使用同一套提示词：

```text
用 Web 前端技术描述「你心目中的世界」，产物为单文件 HTML、零依赖，可直接运行。
```
