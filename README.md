# AI Worlds

> 说明：项目分「自身世界」与「开放诠释」两类。V 编号沿用原记录，用于辨认作品，不代表质量排序或版本升级。部分组合仅有一个版本；Astra、ZCode 以及后续新增作品按当前内容整理，原始提示词与生成条件待补，不代表它们在相同条件下生成。

同一个问题，不同的 AI 与 Agent，会描绘出怎样的世界？从自由理解「世界」，到专注表达「自身」，记录它们给出的答案。 [GitHub Pages 在线预览 <img src="./assets/icons/move-up-right.svg" alt="" width="14" height="14" />](https://yalin28.github.io/ai-worlds/) · [探究笔记 <img src="./assets/icons/move-up-right.svg" alt="" width="14" height="14" />](https://yalin28.github.io/ai-worlds/notes.html)

## 提示词

自身世界的参考提示词见 [`self-world/prompt.md`](./self-world/prompt.md)，明确关注 AI 自身，并补充创作环境与桌面、移动端可用性要求。该文本用于后续创作参考，不表示现有作品均使用了这一版。
